How to use Solana Token Creator

Follow these simple steps:

  1. Connect your Solana wallet.
  2. Write the name and symbol.
  3. Choose decimals. 9 is the usual meme-coin setting.
  4. Set the supply and a short description.
  5. Add a logo. A local file is published so wallets can load it.
  6. Click Create Token and approve once. You pay Solana account rent only, with no Metaplex name fee.
